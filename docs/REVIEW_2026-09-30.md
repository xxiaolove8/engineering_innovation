## 资料检查与适用边界

核心板 IO 表中 PC0–PC5/PF6–PF8 可独立使用，PC6/PC7/PB6/PB7 在不接 Camera 时可作普通 IO；PE9、PF0–PF2 与 SRAM 共用，PG10 为 SRAM CE。归档原理图和新版接线表中的所用排针关系相符。归档原理图的 SRAM 型号/文件版本并不完全等同 V3.1 引用的 ATK-DNM144Z-M4 资料，因此只采用已核对的共用资源关系，未宣布实物版本一致。

Echo 与灰度维持 V3.1 的直连/No Pull 方案。旧版通用 HC-SR04 强制分压、PF3 接灰度 OUT 的建议已撤出当前接线文件。完整电平保证、上电次序和触发门限需原模块手册及实测，不能用 STM32 单个引脚耐压结论替代整条网络验收。

DS3218 数据表第 1/2 页给出 4.8–6.8 V 电源范围；第 2/2 页给出 5 V 堵转 1.8 A、500–2500 µs、1500 µs 中位、50–330 Hz。当前 1300–1700 µs 是初始机械保护范围，不是该舵机额定全行程。

DX-BT24 技术手册电源表给出裸模块 VBAT 2.8–3.6 V、典型 3.3 V。AT 手册第 5 页给出 9600 8N1 与 FFE0/FFE1/FFE2，第 19–20 页说明通知/写入特征。6 针底板能否接 5 V 依赖实际底板稳压电路。AT 命令需在模块命令模式下另行设置；固件不在比赛期间改模块参数。

## 验证

运行 `python tests/run_tests.py`：三组本机 C 测试（控制/PID、Flash 记录、硬件/应用）与 Python 协议、BLE、引脚一致性测试。

新增回归包括三路轮询与错误定时器回调、16 位 Echo/编码器回绕、8 地址/50 µs 数字读取、卡高/缺下降沿/过期值、采样期间上一结果保留、UART 溢出后行重同步、C 应用 v2 字段、中路障碍及全状态停机、终点不依赖计数、BLE 拆分通知/20 字节写入/FFE1 回退/失效会话/连接清理，以及归档表中全部 24 根信号与软件和 CSV/IOC 对照。

验证结果：**3 组 C 测试、16 项 Python 测试全部通过**；Debug/Release 交叉构建均通过，固件分别占 Flash 58,548 / 43,396 字节，RAM 4,016 / 3,968 字节（含链接脚本预留）。Tkinter 仿真连接、8 位灰度及中路距离显示/输入冒烟检查通过。7 个源资料的大小、SHA256 和原件逐字节比较均通过。

BLE 测试采用模拟 GATT 后端，尚未连接实物 DX-BT24；测试运行时未安装 Bleak，使用实物前按 README 安装依赖。源码和 IOC 的一致性检查不等同本次运行 CubeMX 图形界面重新生成。测距恢复后，绕障阶段会扣除因传感器失效而停止的时长，避免原地停等被当作完成绕行；回归用例已通过。
