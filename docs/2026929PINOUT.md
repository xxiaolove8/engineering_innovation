## 0. 工程版本、已确认项与边界

本版对应用户上传的 `NEWESTProPrj_工创分散实训小车主控板_2026-09-29.epro2`，大小252161字节，工程编辑器版本4.1.60。

SHA256：`523AC0C17B9F0D428ABD6AA84F86723254952C9E43B3041C24CF4AD324DDE7A5`。

已独立读取该工程的符号、数字引脚、封装、导线和网络属性：24根信号端点均与本表一致；23个实际元件的数字引脚集合与关联封装焊盘集合匹配；主要电源网未发现意外合并。这是源数据复核，不是由助手重新运行EDA内置DRC。详情见《最新工程审核_2026-09-29.md》。

用户提供的23:09:28 DRC为：致命错误0、错误0、警告8。此后仅口头说明“改好了”的修改不自动算作已审核；验收时应以新导出的工程和DRC记录为准。

本版确认：

- GRAY_OUT已从PF3 / H1-46改到PC5 / H1-16；旧PF3端点已标不连接，不是待实施建议。
- H1-3 / RESET没有接地，并标不连接。
- GPIO功能放在“引脚名称”，数字1、2……放在“引脚编号”，与PCB焊盘一致。网络名称仍由实际导线/网络标签定义，不能只靠普通文字。
- 蓝牙PB10=H2-28、PB11=H2-29。不得沿用旧稿错误的26/27号。
- 三路Echo维持直连，不把10kΩ/15kΩ分压或灰度转换芯片列为强制新增器件；电平条件见第5节。
- 现有入口10µF不等于舵机储能设计已验收；详细待办见《待研究与同学验收清单.md》。

可以进入PCB初步布局；在电源预算、接口实物方向等关键条件未确认前，不作为投板批准。V3.0原文留存在work目录；旧接线步骤只用于追溯，当前接线以本文件为准。

## 5. 电平依据及验收

### Echo

P版手册允许3.0~5.5V供电，但未给5V供电时Echo VOH/VOL、Trig VIH/VIL。不能认定Echo必为5V或必为3.3V，低压直连说明也不等于5V供电时固定3.3V输出。

PF6/7/8在ST表7均为FT。核心板正常3.3V供电、数字/定时器输入、No Pull、不启用模拟功能且满足ST数据手册条件时，可接收符合条件的3.3V或5V数字电平，因此本版不强制分压。ST DS8626表14在VDD为2.0～3.6V时给出FT输入工作范围−0.3～5.5V，并要求输入高于VDD+0.3V时禁用内部上/下拉；设计不能把边界值当作过冲余量。调试核验Echo高低电平/过冲及3.3V Trig触发可靠性，不把万用表脉冲平均值当峰值。

若原Echo为3.3V，旧10k/15k会降到1.98V，缩小高电平余量。FT不是噪声、掉电或接错线的全面保护；外设不得独立上电后持续向掉电核心板送信号，不带电插拔。

### 灰度

模块按手册供5V；AD0/1/2选择CD4051通道，OUT数字输出，EN已有10kΩ下拉。配套F103教程用3.3V推挽输出PA0/1/2直接驱动地址、PA3直接读OUT；配套小车教程也是5V模块与STM32直接接线。这是供应商应用依据，不是完整最坏条件保证表。

本版PF0/1/2直接输出地址，PC5 FT数字输入/No Pull读取OUT。不要在地址线上分压；不默认增加升压或输出缓冲芯片；不用ADC。

AD2 AD1 AD0：000→CH1，001→CH2，…，111→CH8；切换后按例程先等待50µs。黑白对应按实物校验。核对实际CD4051门限与3.3V地址输出裕量，并实测全部8通道选通和OUT电平；依据规格与测试决定是否需要转换，不盲加器件，也不把单次试通当作最坏条件保证。

## 6. 定时器、软件约束

| 用途 | 资源 | 约束 |
|---|---|---|
| 电机两路PWM | TIM5 CH3/CH4 / AF2 | 同频，占空比独立 |
| 左编码器 | TIM3 CH1/CH2 / AF2 | 编码器模式 |
| 右编码器 | TIM4 CH1/CH2 / AF2 | 编码器模式 |
| 舵机 | TIM1 CH1 / AF1 | 周期/脉宽按实物，不直接冻结50Hz |
| 左/中/右Echo | TIM10 CH1 AF3 / TIM11 CH1 AF3 / TIM13 CH1 AF9 | 单通道16位捕获，边沿配对、超时和回绕 |
| 蓝牙 | USART3 / AF7 | 波特率按模块 |
| 灰度 | PF0/1/2输出，PC5输入 | 数字扫描 |

TIM10与TIM1更新共享TIM1_UP_TIM10；TIM11与TIM1触发/换相共享TIM1_TRG_COM_TIM11；TIM13与TIM8更新共享TIM8_UP_TIM13。中断内区分事件，不照搬双通道PWM Input例程。分频依据真实APB定时器时钟。三路探头轮流触发，不同时发射。

先确保PG10高、FSMC/DCMI不用；STBY/TRIG保持低；配置方向/PWM/捕获/UART/灰度，再按需使能电机。GRAY_OUT使用GPIOC Pin5并开启GPIOC时钟，逻辑名保持不变。复位/程序下载期间STBY是否可靠为低仍须核对D24A板上的上下拉与硬件默认状态，不能只靠程序运行后拉低。

## 7. 电源、现有电容与验收状态

电池→D24A Vin；D24A 5V/GND→J13→载板+5V/GND→核心板/5V外设。电池匹配电机与模块额定范围；商品输入5.5～15V、输出5V 5A只是商品标称，不是实际峰值能力和热余量测试结论。

核心板USB_5V经F1直接连VCC5，未画电源择一路径；保险丝不隔离回灌。当前普通USB供电与外部5V二选一。外供电下使用SWD时，确认调试器不另外输出供电；Vref检测脚和电源输出脚不能混淆。若要USB和外部电源同时连接，必须另行审核真实电源会合路径。
