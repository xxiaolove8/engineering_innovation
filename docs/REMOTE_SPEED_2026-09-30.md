# 遥控回车与电机 PID 轮速测试

2026-10-01 更新：调试控制页增加显式 PWM 上限解锁，手动电机输入改为百分比；本文的 300‰ 为默认上限，完整更新见 [PWM 全范围测试与参数说明](DEBUG_PWM_2026-10-01.md)。

2026-09-30 增加独立“遥控回车”页面，并将电机 PID 编辑、目标/实测速度、PWM 与趋势放到同一页。正式比赛仍由 STM32 自动运行，遥控仅用于测试后返回和台架检查。

## 遥控回车

1. 连接 JDY-31 出站 COM 或 USB-TTL，也可先用界面仿真。
2. 自动运行中先点击顶部“停止 / 待机”；测试已完成或普通故障状态可直接点“进入遥控”，界面会先 STOP 再 DEBUG。硬件故障禁止进入。
3. 按住方向按钮控制前进、倒车和前轮转舵。动力设置范围 0–300‰，转舵偏移 0–200 µs，以 1500 µs 为中位。左右后轮使用相同有符号 PWM；前轮转向，不能原地差速旋转。
4. 使用 W / ↑ 前进，S / ↓ 倒车，A / ← 左舵，D / → 右舵，可同时按前进/倒车与转舵。单独转舵不驱动电机。键盘只在遥控页面的非输入控件响应，输入参数或 Ctrl/Alt 组合不会触发移动。
5. 松开最后一个方向键/按钮、离开按钮、窗口失焦或切页会发送 `DRIVE 0 0 1500`。空格执行归零停车，Esc 执行 STOP 至 IDLE；停止时仍按下的方向键必须松开再按，防止按键重复事件恢复驱动。

遥控使用既有 `DRIVE left_pwm right_pwm steer_us`，为直接 PWM，不使用速度 PID。旁边监看仍持续显示实测轮速与 PWM；闭环目标列在此模式为零。方向与机械转舵以已校准的接线和 `car_config.h` 为准。

## 电机 PID 同页调试

“PID 调参”左侧是电机 Kp、Ki、Kd、自动目标和基础 PWM；右侧持续显示左右目标、实测和 PWM，绿线为左轮、蓝线为右轮，实线为实测、虚线为目标，保留最近 80 次采样。

抬起驱动轮，在该页点击“进入调试”，设置右侧左右目标并按住“轮速测试”。两轮目标独立设置，各为 0–500 编码器计数 / 10 ms；一侧设 0 可只测试另一轮。闭环试跑使用正式自动运行的速度 PID 参数，测试输出限制 0–300‰；正常自动模式仍为 0–500‰。左侧“自动目标速度”是自动行驶基准，也决定前馈比例；右侧测试目标独立设置，初次连接时取当前自动目标值。

按住期间参数与目标输入锁定，实时监看继续刷新。松开、失焦或换页归零。暂停后修改左侧五项电机参数，点击“停车并应用电机参数”：验证全部输入，优先取消排队旧控制，执行 STOP，再逐项 PID SET 并读回当前参数/保存状态。完成后保持 IDLE，**不会自动重启**。需要再次进入调试并按住试跑，观察新参数的响应；满意后停车并保存 Flash。

固件 PID SET/SAVE/LOAD/RESET 仍只允许 IDLE；此页面通过停车事务完成调参，不放宽运行中的固件权限。若多项写入中途失败，界面查询实际当前值，须根据错误与读回结果再处理；这不是 Flash 原子批量提交。

## 固件与电脑协议

新增指令：

```text
DEBUG               → OK
SPEED 20.000 20.000  → OK
CTRL?               → CTRL error measured_l measured_r target_l target_r pwm_l pwm_r steer_us
SPEED 0 0           → OK
STOP                → OK
```

`SPEED` 仅硬件就绪且 DEBUG 时可用，接受两个有限十进制/指数目标，不接受 NaN/Inf、溢出/下溢、十六进制或尾部垃圾；非法状态或目标返回 `ERR STATE_OR_RANGE`，硬件故障返回 `ERR HARDWARE`。电脑客户端发送三位小数。

GUI 每约 200 ms 更新 DRIVE/SPEED，二者共享驱动队列和 500 ms 车端看门狗；遥测在运行中安排更频繁查询，实际刷新率受 9600 bps 与链路延迟影响。合并旧续发避免积压，归零优先处理；STOP 和停车调参取消同会话全部待执行请求。已在等待响应的请求仍须完成或超时。

相同 SPEED 目标续发只更新看门狗，不清积分；新目标或从 PWM 切到闭环重置控制历史。抗积分饱和按调试的 300‰ 上限处理，不在自动 500‰ 控制输出之后简单裁剪。SPEED 0 0、DRIVE 切换、STOP、退出或看门狗超时会清除旧闭环目标。

DEBUG 直接 PWM 和 IDLE 也采集实测轮速，避免监看显示固定零；DRIVE 续命保留最近测量值，避免命令之间出现假零。速度按编码器增量和实际采样时长归一化为**计数 / 10 ms 的绝对值**；有符号增量仍在 STATUS 中。未标定轮径/编码器比例前不转换为 m/s。

ASCII 协议版本仍为 2，但旧 v2 固件没有 SPEED；使用该功能须更新本次 HEX/ELF。收到 ERR COMMAND 后界面归零并显示错误，不降级成直接 PWM 伪装闭环。仿真使用简化一阶电机响应与有界 PID，仅演示界面/协议，不代表真实车辆动力学。

- 6 个原生 C 测试程序覆盖 SPEED 解析、状态/硬件拒绝、独立目标、零目标、300‰ 限幅与抗饱和、同目标续命积分保留、500 ms 停止、PWM/闭环切换及真实 CTRL 测量。
- Python 全套 101 项通过，包括 23 项真实 Tk 控制器回归，覆盖遥控方向/限幅、键盘组合、编辑框忽略、归零/失焦/换页、急停防重启、SPEED 释放、停车调参和三处图表/共享数值同步。
- 默认 1180 × 840 与最小 1000 × 700 的各页尺寸检查通过，两个新增页面内容宽度可容纳；默认 PID 页试跑按钮与曲线同时可见，较小窗口可滚动访问。
- Debug / Release 构建通过，更新 HEX/BIN；FLASH 64024 / 46720 B，RAM 4160 / 4120 B。
