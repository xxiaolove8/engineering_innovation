# PWM 全范围测试与速度参数说明

## GUI 操作

连接新版固件，打开“调试控制 → PWM 全范围测试入口”。输入本次测试上限，例如 50 或 100，点击“停车并解锁此上限”。软件先 STOP、再进入 DEBUG、写入上限并读回；完成时电机仍为 0。下方左/右电机输入是 **百分比**，例如左 50、右 0，按住“驱动 / 调舵”才输出左侧 50% PWM；负数表示反向。100% 是最大占空比，不能超过。

解锁同时适用于 PID 页的轮速测试。遥控回车保持 30% 的 GUI 输入上限；AUTO 输出仍最高 50%。松手、移出按钮、窗口失焦或换页归零。STOP、退出 DEBUG、硬件故障或运动中 500 ms 未续发 DRIVE/SPEED，固件恢复默认 30% 上限。静止编辑与正常松手保留本次解锁，断开调试连接会尝试 STOP。

支持 0.1% 精度（协议是千分比）。输入限额与手动输出都会校验有限数字、范围，NaN/Inf 和大于100%的值不会发送为驱动命令。GUI 显示固件读回的实际限额，检测到看门狗重锁后同步更新。解锁不是 Flash 参数，下次启动仍默认30%。

## “基础速度”与“基础 PWM”

界面现在称为 **自动基准速度** 和 **前馈 PWM**：

- 自动基准速度（`target_ticks`）：自动直行时想达到的速度，也是前馈的参考点。单位是编码器计数/10 ms，不是 PWM 百分比、RPM 或 m/s。弯道会在此目标上再调整速度。
- 前馈 PWM（`feedforward_pwm`）：经验上达到这个参考速度大约需要的输出。单位为‰，例如215‰就是21.5%。它不是固定的最终PWM，也不是最低起转PWM。
- 左/右测试目标：PID 页独立设置本次想达到的速度，不直接修改自动基准速度。

速度控制先估计输出，再用实际编码器速度纠偏：

```text
前馈输出 = 前馈 PWM × 本次速度目标 ÷ 自动基准速度
最终输出 = 前馈输出 + PID 修正，随后按当前模式上限限幅
```

以本次左电机 5 V 台架参数为例，自动基准速度5、前馈PWM215：

| 本次速度目标 | 前馈起步估计 |
| ---: | ---: |
| 5 计数/10 ms | 215‰ = 21.5% |
| 10 计数/10 ms | 430‰ = 43% |

如果实测比目标慢，PID增加输出；如果偏快，PID减少输出。目标10时，默认30%上限会截住上述43%估计；显式解锁后上限才可提高。这只是前馈比例说明，不是目标10的实测标定结果。

**手动PWM测试忽略这些速度和PID参数**：手动填50%就是直接给50%占空比，速度由供电、电机、减速箱和负载决定。要比较电机在各占空比的能力，用手动PWM；要保持某个实测速度，用PID轮速测试。更换VM电压或负载后应重新核对前馈和PID。

## 协议与兼容性

```text
DEBUG LIMIT?       -> LIMIT 300
STOP               -> OK
DEBUG              -> OK
DEBUG LIMIT 1000   -> OK
DEBUG LIMIT?       -> LIMIT 1000
```

设置接受整数1..1000‰，只允许硬件READY、DEBUG、左右动力输出为0且速度测试未激活。非法状态/范围返回`ERR STATE_OR_RANGE`，硬件未就绪返回`ERR HARDWARE`。查询任何状态可用，不续发动力指令。DRIVE和SPEED分别保持原有格式，二者的输出均服从本次上限，SPEED积分抗饱和也使用同一上限。

协议版本仍为2，因此PONG 2不代表支持解锁。旧固件返回ERR COMMAND，GUI显示“旧固件不支持解锁，请烧录新版固件”，按钮禁用；原低PWM功能继续可用。更新GUI不会绕过板端旧30%限制。

固件已生成 [Release HEX](../build/Release/if_car.hex) 和 [Debug HEX](../build/Debug/if_car.hex)。本次检查未检测到ST-Link，尚未烧录，未在真实电机上运行超过30%的输出。仅执行现有COM5的只读GUI兼容性检查，成功读取待机状态并识别旧固件。

烧录会重启并丢失未保存的RAM参数；之前左电机低速参数为Kp8、Ki20、Kd0、基准速度5、前馈PWM215‰，需要时在新GUI重新应用。旧Flash保存记录格式未改变，解锁不写Flash。
