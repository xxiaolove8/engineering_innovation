本记录保留当时的现场结果。后续蓝牙已改为 JDY-31 SPP；当前电脑连接使用出站 COM，详见 [模块更新说明](MODULE_UPDATE_2026-09-30.md)。

晚间用户补充：实际舵机型号 DS3218MG，电源模块输出 5 V，但舵机电源负极**没有连接 STM32 GND**；板上烧录的程序仍不确定。未共地是已确认的接线问题，应断电后先连接公共地。新增官方例程的交叉核对、接线与测试步骤见 [舵机例程对照](SERVO_EXAMPLE_REVIEW_2026-09-30.md)。以下 Bootloader 读数属于此前现场记录，不能据此判断晚间板子的实时状态。

## 本次现场只读结果

用户报告：PE9 对地万用表交流档低于 1 V，直流档零点几伏，舵机完全不动。

通过 ST-Link HOTPLUG 读取，未停机、复位、写寄存器或烧录：

| 项目 | 实际读数 | 说明 |
| --- | --- | --- |
| SCB VTOR（0xE000ED08） | 0x1FFF0000 | 向量表位于 STM32 系统 ROM；结合此前系统内存映射与 RAM 的 Bootloader 描述符，当前运行内置 Bootloader。 |
| RCC APB2ENR | 0x00004000 | TIM1EN bit0=0，TIM1 时钟关闭。 |
| TIM1 CR1 / PSC / ARR / CCR1 / BDTR | 均读为 0 | 外设时钟关闭时这些读数不能当作完整有效配置，但足以结合 TIM1EN=0 确认目前没有运行舵机定时器。 |
| GPIOE 寄存器 | 均读为 0 | 当前 GPIOE 时钟关闭，不能据此推断 PE9 外部波形或负载电压。 |
| ST-Link 目标电压 | 3.28 V | 这是 MCU 电源参考，不是舵机电源。 |

当前未运行小车应用，不能生成预期的 PE9 PWM。这是本次舵机完全不动的直接软件状态原因；尚未确定进入 Bootloader 的触发原因。请确认 BOOT0=0 后复位，再复核 PWM。STM32 系统 Bootloader 与启动选择参见 [ST AN2606](https://www.st.com/resource/en/application_note/an2606-introduction-to-system-memory-boot-mode-on-stm32-mcus-stmicroelectronics.pdf)。

## 源码核对

- PE9 / H1-36 / J1-3：TIM1_CH1、AF1、推挽输出、无上下拉。
- TIM1 输入时钟 168 MHz；PSC=167，所以计数频率为 1 MHz。
- ARR=19999：每 20 ms 一个周期，即 50 Hz。
- PWM1、高电平有效；CCR1=1500 为 1.5 ms 中位脉冲。转向机构限制为 1300–1700 us。
- `HAL_TIM_PWM_Start(&htim1, TIM_CHANNEL_1)` 在真实 HAL 中启用 CC1E、高级定时器 MOE 和 CEN，不缺失主输出使能。
- PG10 在配置 PE9 之前置高，保持共用 PE9/D6 的板载 SRAM 未选中；工程未启用 FSMC。
- CarHw_Init 先启动三路测距计时器并检查微秒时钟，再启动舵机。如果此前启动失败，舵机不会启动；新版可由 `HW?` 查询具体失败阶段。
- 当时新固件尚未烧录，源码配置不能代表板上已烧录固件；晚间用户仍无法确认烧录版本。

未发现需要通过提高占空比或改变输出电压解决的源码错误，保持现有舵机控制参数。

## 正常 PWM 下如何测量

信号的高电平峰值约为 MCU 的 3.3 V；中心位置每周期高电平仅 1.5 ms，其余 18.5 ms 为低电平。直流平均值约为：

`3.3 V × 1.5 ms / 20 ms = 0.2475 V`

1300–1700 us 范围内，理论直流平均值约为 0.215–0.281 V。交流档读数取决于仪表带宽、耦合方式和是否支持真有效值，不能把读数当作脉冲峰值。这些计算针对正常 PWM，不代表本次现场已存在波形。

用示波器或逻辑分析仪测 PE9 对 MCU GND，检查约 3.3 V 高电平、20 ms 周期、1500 us 高电平宽度。先确认波形，再检查舵机供电与信号线。J1-1=GND、J1-2=+5V、J1-3=PWM；舵机地与 MCU 地相连。工程内 DS3218 datasheet 给出供电 4.8–6.8 V、中心 1500 us、频率 50–330 Hz。PE9 为信号线；测舵机供电应测 J1-2 对 J1-1。
