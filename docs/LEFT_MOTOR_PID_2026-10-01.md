# 左电机实机 PID 与低速排查记录

日期：2026-10-01。用户确认串口、TB6612、编码器和电源已连接，并固定电机供台架测试。电机为 520 编码器减速电机，VM 当前接 5 V；额定电压、减速比、额定转速和每圈计数尚未确认。正向命令对应的实际车辆前进方向尚未确认。

## 实机条件与结果

- 使用板载 CH340 / COM5，9600 8N1，DTR/RTS 在打开前设为 False。
- 握手 `PONG 2`，硬件 `HW 1 READY`。所有动力测试只使用 DEBUG；右电机目标和输出始终为 0。
- 原 RAM 参数：`speed_kp=3`、`speed_ki=1`、`speed_kd=0`、`target_ticks=20`、`feedforward_pwm=250`；初始保存状态为 `STORE UNSAVED`。
- 当前 RAM 参数：`speed_kp=8`、`speed_ki=20`、`speed_kd=0`、`target_ticks=5`、`feedforward_pwm=215`。其他 PID 项维持读到的原值。
- 未写入 Flash、未重新烧录、未改变固件 PWM 上限。左右轮目前共用这一组速度参数，右电机和带载条件尚未标定；重新上电会按固件默认值或已有 Flash 记录加载。
- 每一段结束后执行 STOP 并核验 IDLE、左右 PWM 为 0。单次 SPEED 后停止续发，等待 650 ms，再读 CTRL/STATUS，确认目标和输出均归零；随后 STOP 至 IDLE。

速度单位均为 **编码器计数 / 10 ms**，不是 RPM 或 m/s。UART 读取的是控制周期速度快照，低速有整数计数量化；下表是稳定窗口内快照均值，不能当作高速同步采集结果。

## 为什么现在转不快

1. **确定的软件限制**：DEBUG 的开环/闭环输出最高 300‰（30%）；AUTO 速度输出最高 500‰（50%）。源码分别在 `Core/Src/car_pid.c` 和 `Core/Src/car_logic.c` 限制，底层 `Core/Src/car_hw.c` 按 `PWM/1000` 写 CCR。`300` 不是 100%。
2. **已测到当前调试上限**：在用户确认的 5 V VM 下，开环 300‰ 约为 7.58 计数/10 ms。历史日志的目标 20、实测 7–8、PWM 300 与本次测试一致。提高 PID 不能突破已达到的输出上限。
3. **目前低速目标是有意设定的**：新参数目标 5 时，控制器主动保持约 21.5% PWM。这次校准的是低速跟踪，不是让电机全速运转。
4. **电压匹配待确认**：VM=5 V 不代表电机额定电压为 5 V。若铭牌确为 12 V，当前供电和 30% PWM 显然无法提供额定电压下的工作条件。理想平均驱动电压可粗估为 `VM × 占空比`：5 V × 30% ≈ 1.5 V，5 V × 21.5% ≈ 1.075 V；这不是实测电机端电压，未计驱动压降、电源跌压和反电动势，不能按此比例精确推算转速。
5. **减速比与测速单位待标定**：只写“520”无法确定输出转速。若输出轴一圈的实际计数为 C，则 `RPM = 6000 × 计数/10 ms ÷ C`。厂家若给的是减速前单相 PPR，应结合本工程 TI12 四倍频和减速比换算；若已经是四倍频 CPR，则不能重复乘 4。

TIM5 配置对应 20 kHz PWM。底层每个控制周期会短暂关 STBY、清 PWM 后更新输出；函数内没有长等待。目前没有示波器波形证明这段门控造成严重降速，不把它认定为故障原因。

电源带载是否跌压、TB6612 是否过热/电流不足、机械负载是否过大，当前没有电压、电流和温度测量证据。TB6612 数据手册列出 1.2 A/通道平均电流的绝对最大额定值，工作范围输出条件为 VM≥4.5 V 时 1.0 A，3.2 A 仅为 10 ms 单脉冲条件；不能把 3.2 A 当连续能力。实际模块还受 PCB 散热影响。

下一步先核对电机铭牌或购买页面的额定电压、额定/空载转速、减速比、编码器规格及堵转电流，测量运行时驱动板 VM–GND 电压。若更换 VM 或解除输出限制，应重新进行低 PWM 校准；不要沿用本次 5 V 参数直接判定高电压效果。载板 `J13/+5V` 是主控稳压后输入，不能随电机电源一起升压；实际 VM 独立电源走线及模块电容额定电压须按实物核对。

## 用户自行复测

在 GUI 的 PID 调参页输入 Kp=8、Ki=20、Kd=0、自动目标=5、基础 PWM=215，点击“停车并应用电机参数”。右侧左测试目标设 5、右测试目标设 0，进入调试，固定电机外壳并让车轮悬空，再按住“轮速测试”。松开立即归零；顶部“停止 / 待机”或 Esc 停车。

等价参数命令（每行以 LF 结束）：

```text
STOP
PID SET speed_kp 8
PID SET speed_ki 20
PID SET speed_kd 0
PID SET target_ticks 5
PID SET feedforward_pwm 215
PID?
DEBUG
SPEED 5 0
```

`SPEED 5 0` 要约 200 ms 原样续发才能持续测试；手动偶尔发一条会触发 500 ms 停止，不能据此判断 PID。结束发送 `STOP`，再查 `STATUS?`、`CTRL?`。确认左右电机、负载与供电均适用后，可在 IDLE 保存到 Flash。
